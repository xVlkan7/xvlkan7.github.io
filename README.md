# Resume Website

Generally basic website acting as a live resume. Not meant to be the greatest design work of all time,
mainly focused on loading nearly instantly, keeping a simple & clean codebase, and high functionality.

## Features

    Ability to download contact and resume
    Career history section
    Blog section, for any writing I do
    Projects section, so people can see what I'm currently working on

## Tech Stack

    Frontend: HTML/CSS/JavaScript
    Framework: None. Simplicity is king.
